in powershell :
download and install chromadb
---------------------
iex ((New-Object System.Net.WebClient).DownloadString('https://raw.githubusercontent.com/chroma-core/chroma/main/rust/cli/install/install.ps1'))

Verify installation : Open a new PowerShell window and run:
---------------------------

chroma --help

or

chroma version		

to run 
chroma.exe run --host 0.0.0.0 --port 8000  (When you omit --path, Chroma uses its default data directory.)
OR
chroma.exe run --host 0.0.0.0 --port 8000 --path D:\chromadb-data

creating database named "SpringAiDatabase"
Invoke-RestMethod `
-Uri "http://localhost:8000/api/v2/tenants/SpringAiTenant/databases" `
-Method POST `
-ContentType "application/json" `
-Body '{"name":"SpringAiDatabase"}'

-Method POST `
-ContentType "application/json" `
